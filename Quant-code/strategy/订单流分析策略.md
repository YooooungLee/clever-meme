# 订单流分析策略

## 策略思路

订单流分析是一种深入洞察市场微观结构的交易方法，它通过分析市场中买卖订单的实时流动来预测价格可能的走势。在传统技术分析中，我们往往关注价格和成交量这两个基本面，而订单流分析则更进一步，试图理解市场参与者的行为意图。

<u>当市场出现异常大的成交量，同时伴随着显著的价格变动时，这往往意味着大资金的进场或离场。通过分析买卖压力的变化，我们可以判断这种异动背后的方向性，从而做出相应的交易决策。</u>

# 订单流分析策略

## 策略核心思路

本策略通过分析市场订单流（成交量、价格波动、买卖压力等）来捕捉主力资金异动，判断多空方向并自动进行风控。适用于日线及更短周期的量化回测和实盘交易。

## 计算逻辑与指标说明

1. **参数自适应**
   - 支持自动或手动选择K线周期（分钟、小时、日线等），参数会根据周期自动调整。
   - 主要参数包括成交量阈值、价格变化阈值、回溯期间。

2. **核心指标计算**
   - **VWAP（成交量加权平均价）**：作为价格参考基准，判断主力行为。
   - **成交量动量**：判断当前成交量是否放大。
   - **相对成交量**：当前成交量与均值（EMA）比值，识别异常放量。
   - **价格变化百分比**：当前收盘价与VWAP的偏离程度，捕捉剧烈波动。
   - **买卖压力**：上涨K线计入买压，下跌K线计入卖压，取差值做EMA平滑。

3. **信号生成逻辑**
   - **多头信号**：成交量异常放大 + 价格剧烈上涨 + 买压占优 + 收盘高于VWAP + 成交量动量为正。
   - **空头信号**：成交量异常放大 + 价格剧烈下跌 + 卖压占优 + 收盘低于VWAP + 成交量动量为正。

4. **风控与交易管理**
   - 自动设置止损和止盈，参数可调。
   - 多空方向分别独立平仓，止损止盈合并为一条指令，避免标签混淆。
   - 每笔交易平仓时自动在图表上标记“盈利”或“亏损”，并显示具体金额（保留两位小数）。

5. **可视化设计**
   - 买卖压力柱状图（绿色为买压，红色为卖压）。
   - 成交量比率线（蓝色），阈值虚线（灰色）。
   - 背景色标记多空信号（绿色为多头，红色为空头）。
   - 盈亏标签自动显示在平仓K线下方。

## 主要参数说明

- `volumeThreshold`：成交量异常阈值，默认2.0倍。
- `priceChangeThreshold`：价格变化阈值，默认0.5%。
- `lookbackPeriod`：均值回溯周期，默认20。
- `useStopLoss`/`useTakeProfit`：是否启用止损/止盈。
- `stopLossPercent`/`takeProfitPercent`：止损/止盈百分比。

## 策略优势与适用场景

- 适合捕捉主力资金异动、短线波动、趋势反转等场景。
- 支持多周期自动适配，适合日内、波段、趋势等多种风格。
- 风控机制完善，盈亏标签直观，便于回测和实盘复盘。
