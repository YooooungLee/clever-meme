# 艾略特波浪理论

艾略特波浪理论（Elliott Wave Theory）是由拉尔夫·尼尔森·艾略特（Ralph Nelson Elliott）在20世纪30年代提出的一种技术分析理论。该理论认为，金融市场的价格运动遵循一定的模式，这些模式可以被分解为一系列的“波浪”，这些波浪反映了市场参与者的心理和行为。

## 策略思路
艾略特波浪理论的核心思想是市场价格运动可以分为两种主要类型的波浪：推动波（Impulse Waves）和调整波（Corrective Waves）。推动波由五个子波「1，2，3，4，5，」组成，表示市场的主要趋势方向，而调整波由三个子波组成「a,b,c」，表示市场的反向调整。
